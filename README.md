# המוסך של טוטי 🚗

משחק מכוניות לילדים בגילאי 3–4. לוחצים, מפעילים ולומדים צבעים, ספירה וצורות.

## המשחקונים

| משחקון | מה לומדים |
|---|---|
| רמזור | צבעים וכללי זהירות בדרכים |
| שטיפה | ספירה עד 5 |
| צבעים | שמות של 6 צבעים |
| חניה | עיגול, ריבוע, משולש, כוכב |
| רכבי הצלה | כבאית, אמבולנס, משטרה |
| בונים מכונית | ספירה עד 4 |

## איך משחקים

פותחים את `index.html` בדפדפן, או את הכתובת של GitHub Pages בטלפון.
כל המשחק נמצא בקובץ אחד, בלי התקנות ובלי שרת.

- הוראות בקול בעברית (מהקול המובנה של המכשיר) וגם בכתב.
- אין דרך לטעות: לחיצה לא נכונה נותנת רמז.
- כוכב על כל הצלחה, וחגיגה כל 5 כוכבים.
