# המוסך של טוטי 🚗

משחק מכוניות לילדים בגילאי 3–4. לוחצים, מפעילים ולומדים צבעים, ספירה, צורות ומילים.

**לשחק:** https://krmy1979.github.io/tooti-garage/

## 9 משחקונים

| משחקון | מה לומדים |
|---|---|
| רמזור | צבעים וכללי זהירות (ברווזים חוצים באדום) |
| שטיפה | ספירה, מ־3 עד 5 כתמים |
| צבעים | שמות של 6 צבעים, משחק חופשי ואז "צבע בכחול" |
| חניה | צורות: עיגול, ריבוע, משולש, כוכב, לב (2 עד 4 אפשרויות) |
| רכבי הצלה | כבאית שמכבה שריפה, אמבולנס ומשטרה |
| בונים מכונית | ספירת 4 גלגלים, פנסים וצפצפה |
| מרוץ | ספירה לאחור, סיבה ותוצאה (לוחצים מהר, נוסעים מהר) |
| תחנת דלק | ריק, חצי ומלא |
| משאית זבל | מיון לפי צבעים (2 ואז 3 פחים) |

## המוסך שלי

כל 3 כוכבים פותחים כלי רכב חדש: מונית, אוטובוס, כבאית, טרקטור, משטרה, משאית זבל, מכונית מרוץ, אמבולנס, משאית גלידה, מחפר, מערבל בטון וגרר. לחיצה על רכב במוסך משמיעה את הצליל שלו ואת השם שלו.

## עוד

- הוראות בקול בעברית (מהקול המובנה של המכשיר) וגם בכתב, ומוזיקת רקע עדינה.
- אין דרך לטעות: לחיצה לא נכונה נותנת רמז, ואחרי 7 שניות בלי לחיצה מופיע רמז.
- הקושי עולה בהדרגה בכל משחקון.
- אזור הורים: לחיצה ארוכה על גלגל השיניים. מציג התקדמות, מכבה מוזיקה או קול, ומאפס.
- הכל בקובץ אחד, `index.html`, בלי התקנות ובלי שרת. ההתקדמות נשמרת במכשיר.
